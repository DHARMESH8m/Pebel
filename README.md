# Pebel website

This is a static website prepared for Vercel.

## Deploy on Vercel

1. Unzip this folder.
2. Create a new Vercel project and upload/import this folder.
3. Leave the framework preset as `Other`.
4. No build command or environment variables are required.
5. Deploy.

The main page is `index.html`, and all images are stored in `assets/`.

Before connecting `pebel.co`, review the preview with Sharad and replace the current domain only after approval.
